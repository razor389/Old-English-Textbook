# Course decisions

The course structure was agreed on 22 October 2026; all eighteen units were completed on 28 October 2026.

| Decision | Consequence |
|---|---|
| Use the main practical part of Lambdin's Gothic book as a structural model | Organize grammatical systems into coherent units; historical grammar is supplementary |
| Present full paradigms and whole declensions together | Teach complete cases/numbers and characteristic changes when a class is introduced |
| Keep Cook's exercises and vocabulary | Regroup them under the grammar sequence while preserving original identifiers and prompts |
| Multiple Cook exercises may form one chapter | Unit boundaries follow coherent grammatical systems |
| A large vocabulary is acceptable | The unit's requirements determine the list |
| Make readings more substantial | Seek connected passages and provide the verbal/syntactic groundwork as well as vocabulary |
| Assume no prior Old English | Establish every teaching milestone and assignment in the active contracts |
| Use Beads if useful for multiple agents | Seed dependencies and ownership; keep source verification and learning coverage in the editorial records |

Use terse exposition, evidence-based corrections, section endnotes, independent review, and full LuaLaTeX exports. No prior Old English is assumed. Standard grammar terminology is assumed familiar.

The opening noun unit combines Exercises 1–3 and introduces the relevant full declensions, article, basic case uses, stem changes, and the present/preterite indicative copula. Independent source and curriculum work settled the [eighteen-unit outline](../curriculum/COURSE_PLAN.md) and [complete Cook allocation](../curriculum/COOK_MAP.md); the [Unit 1 contract](../chapters/ch01/coverage.json) was saved before prose at `09990cf`. Exercise 4.1–17 belongs to adjective work in Unit 3; its passive command, item 18, is assigned in Unit 7. All 644 numbered Cook items are now assigned and independently reviewed.

Sources consulted for the structural comparison: [Lambdin's contents, reproduced by the book distributor](https://cincinnatistate.ecampus.com/introduction-gothic-language-lambdin/bk/9781597523943) and [the publisher's description and preface excerpt](https://wipfandstock.com/9781597523943/an-introduction-to-the-gothic-language/). The full book was not available for inspection. Use this as an organizational comparison; do not claim a page-by-page adaptation or use Gothic paradigms as Old English evidence.

The requested presentation revision uses the later units' table style throughout: shared verbal plurals print once as **1–3 pl.**, case/person axes are consistent, and a reversible cell mapping preserves complete paradigm coverage. See the [revision contract](revisions/table-layout/contract.json).

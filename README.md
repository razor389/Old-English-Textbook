# Old English: Cook / Lambdin-style course

A new grammar-led Old English course using Cook's exercises and vocabulary, with complete paradigms and connected graded readings. The practical organization of Lambdin's Gothic course is the structural model. Historical grammar is supplementary.

Start with [STATUS.md](STATUS.md), [AGENTS.md](AGENTS.md), and the [course plan](curriculum/COURSE_PLAN.md). The [handoff](docs/HANDOFF.md) gives the next session's starting task; [prompts/START_HERE.txt](prompts/START_HERE.txt) can be pasted directly into it.

The repository is seeded, not a completed new course. No chapter has been drafted or taught here. Grammar and vocabulary registers deliberately start empty. The earlier two-chapter experiment is preserved under [reference/previous-course](reference/previous-course/README.md), with its source evidence, corrections, and complete PDFs. Its learning milestones do not apply to this course.

Use Beads for work tracking: `bd prime`, then `bd ready`. See [the editorial workflow](docs/WORKFLOW.md) for task ownership, dependencies, and the local single-writer setup. The course data remains in the chapter contracts and cumulative registers; Beads tracks the work needed to produce it.

Markdown is the editable master; LuaLaTeX supplies full learner and key PDFs. [Typesetting](typesetting/README.md) carries forward the tested layout.

Seeded 22 October 2026. Local repository; no remote or publication configured.

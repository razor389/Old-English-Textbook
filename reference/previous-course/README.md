# Previous-course reference snapshot

This directory preserves the earlier Cook Expanded experiment at commit `7dd99f938d4969147fe3d996c42a344d9fc4cb90`. Its Chapters 1–2 were reviewed and exported, but they are not Chapters 1–2 of this new course. Source facts, lexical evidence, correction C01, and layout work are reusable. Old teaching milestones, assignments, and reader deferrals are historical only.

Read [the original project overview](PROJECT_README.md) for its contents, [source registry](sources/registry.json) for editions, and [PROVENANCE.json](PROVENANCE.json) for file hashes. The original instruction file is renamed `AGENTS.snapshot.md` so it cannot become active project instructions. All other archived files are unmodified committed bytes. Do not edit the snapshot during ordinary course work.

# Unit 18 independent review

The coordinator alone writes Beads, shared registers, the contract and Git. Reviewers write only assigned review files. Author-preparation audits are sealed evidence, not independent review.

## Before comparison access

The fresh learner reviewer reads the complete actual `chapters/ch18/student.md` and solves every requested answer. Preserve its item and output comment markers in the same order in `chapters/ch18/independent-solutions.md`. Write actual translations and explanations, including honest attempted solutions where the lesson seems insufficient. Record missing teaching and ambiguous instructions; external evidence does not cure missing learner support.

The allowlist is this protocol, `AGENTS.md`, `EDITORIAL_POLICY.md`, the actual Unit 18 learner, earlier accepted learners and contracts, the seventeen-unit registers, and unannotated original primary-page images. Record exact files used and identities. Current key, coverage, brief, audits, proposals, token maps, models, translation witnesses, author readbacks, coordinator review and helper/checker source are excluded until explicit unlock. Do not obtain current answers from authors or other reviewers. Disclose accidental exposure immediately.

Complete every response, notify the coordinator and stop before key access. The coordinator must read and commit the unchanged witness. Only an explicit subsequent message giving that checkpoint unlocks comparison. File existence and elapsed time are not authorization.

## After explicit unlock

Preserve frozen solutions unchanged. Compare every output with the key, target, meaning, alternatives, learner preparation and primary evidence. Distinguish valid language from compliance with a stated exercise target. Identify findings with locators and concrete corrections. Authors/coordinator repair; reviewers change only review files and verify actual repairs.

Write `chapters/ch18/review.md` and `chapters/ch18/review-ledger.json`, recording every task/output separately, actual independence history, findings/resolutions, personally viewed primary images and final master/solution identities. Acceptance requires no material open findings. The coordinator provides the existing machine-readable acceptance schema after unlock.

## Separate paradigm review

A separate fresh non-author reviews every defined system, literal cell and display route against primary images, checking endings, stems, exceptions, lexical meaning and exact production/recognition/supplied scope. This reviewer may read the contract and audits. Checker success or author agreement is not linguistic proof.

Write only `chapters/ch18/reviews/paradigms.json`, `chapters/ch18/reviews/paradigms.md` and assigned reviewer helpers. Record all cells, actual image inspections, findings and verified resolutions, both final masters and substantive contract identity. Do not send answers to the blind solver before unlock.

## Exports

Linguistic acceptance precedes export acceptance. Non-authors actually view every final learner/key page, including special characters, tables, notes and page boundaries. Rendering and text extraction are not visual inspection. Changed pages need renewed inspection; reuse requires a recorded byte-identical comparison to a previously personally viewed image. Complete content parity and clean LuaLaTeX logs are separate gates.
